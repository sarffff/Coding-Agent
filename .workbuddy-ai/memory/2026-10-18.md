## 评估 Caho1/open-claude-ui（Claude 桌面端 UI 复刻）

用户给了 https://github.com/Caho1/open-claude-ui，要求先读一遍。仓库 2026-10-14 创建，TypeScript，MIT，1189 star / 257 fork。

读了：仓库元数据、文件树（82 项）、package.json、src/index.ts、tsconfig.build.json、CdsButton.tsx、ChatComposer.tsx，并查了 npm registry。

结论：
- **npm 上没有 `open-claude-ui`（registry 返回 404）**，README 里的 `import ... from 'open-claude-ui'` 和 `@import "open-claude-ui/css"` 都不成立，只能用源码或 git 依赖。
- 组件绑定 Tailwind（`bg-clay`、`shadow-field`、`duration-fast` 等自定义类）+ framer-motion + lucide-react。
- `ChatComposer` 里是假交互（`handleSimulateAddAttachment`），模型列表还停在 Claude 3.7/3.5/3-opus。
- `src/index.ts` 从 `../code-examples/*` 再导出，依赖 tsc 同时输出 src 与 code-examples，`main` 指向 `dist/src/index.js`，布局脆弱。

对本项目的意义：本项目 desktop 是 React 19 + Vite 8 + 手写 CSS 变量（无 Tailwind、无 framer-motion），所以只能拿它的设计令牌与交互规范当参考，不能当依赖。ChatPanel 已有 `nativeEvent.isComposing` 守卫，缺 `keyCode 229` 兜底。

## 样式重构（以 open-claude-ui 为参考）

只改 `apps/desktop/src/styles.css`（+852/−55），不动任何组件标记，靠「换令牌 + 末尾覆盖层」生效：

1. `:root` / `[data-theme="light"]` 换成 CDS 令牌：陶土橙 `#d97757`（浅色主色用 `#c6613f`）、4 层表面阶梯、alpha 边框、圆角阶梯、动效曲线、双环阴影、`--focus-ring`。既有 375 处 `var(--)` 引用全部沿用，变量名一个没改。

3. 末尾追加「CDS 重构层」：侧栏/顶栏/面板/按钮/输入/会话气泡/输入终端/徽标/代码块/弹窗/滚动条/动效。要点：新对话与发送按钮改陶土实心、主行动 `.run-button` 从 lime 改 clay、用户气泡右下角收口、`.small-action` 统一 28px 高、消息入场 `cds-message-in`、`prefers-reduced-motion` 兜底。

踩坑：`electron` 命令行把额外参数里的 URL 当自己的参数处理，传 URL 会以 127 退出且无输出；改用环境变量传参就正常。另外必须 `unset ELECTRON_RUN_AS_NODE`（IDE 会继承）。
