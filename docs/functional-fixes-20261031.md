# 功能修正与验证（2026-10-31）

本轮落实功能评估后的第一批修正，重点是日常使用中的会话归属、执行准备、Cowork 可靠性、运行期间模型配置和桌面后端恢复。修改基于原有未提交工作继续完成，未提交或部署，未访问真实模型或远端。

## 已完成的使用行为

- 输入、文本附件、完成条件输入及读取/发送状态按会话隔离。A 的迟到创建、成功或失败不会覆盖 B；切走再返回 A 能显示其新回复。完成后的 Code 后续任务拥有独立草稿。
- Code 首次发送只创建任务并打开准备界面，复用已有必跑检查和完成条件编辑。未保存、保存中、恢复未确认或首轮已开始时拒绝启动；启动失败可以在同一任务重试。
- 聊天页显示任务状态说明，提供准备、继续、恢复及执行记录入口。当前会话的审批、继续与恢复防重复点击，其他会话的 Cowork 请求不会挡住这些操作。
- Cowork 使用请求 ID 实现失败重试与成功回放；不重复写入同一用户消息，同 ID 不同文本被拒绝。首条消息创建等待阶段也可以停止；取消后丢弃迟到回复并保留可重试输入。
- Cowork 按请求限制超时与上下文字节，长会话不再被 Code 总预算封锁。复用有限源码读取，不执行模型命令；模型历史最多最近 40 条且受总字节上限约束。原始聊天记录保留到删除对应会话。
- 活跃 Code 循环、整个手动起草或 Cowork 请求期间，影响模型的设置在持久化和替换 Provider 前被拒绝。回复事件保存实际模型与 Provider。
- Electron 报告托管后端启动失败或意外退出，提供重试；并发重启复用同次启动，停止等待子进程真正退出。前端每次请求读取最新 API 地址，后端未就绪时明确失败。
- 助手正文支持基础 Markdown、标题、列表、表格、安全链接和代码复制；上下文路径可以进入文件浏览定位。
