## 已实现

| 使用场景 | 当前行为 |
| --- | --- |
| 查看 Code 结果 | 聊天正文末尾的执行摘要展示当前轮次、去重改动文件数、必跑检查结果和完成条件进度，可进入文件浏览、执行记录与完成复核 |
| 核对验证 | 展示实际命令或清单脚本/目标、工作目录和超时；失败位置可定位文件行号，输出被截断或清理时显示提示 |
| 阅读工具事件 | 展开修改路径、增加/删除行数、检查点、检查 ID、命令、目录及验证状态；工具组标题显示失败数，失败详情默认展开，修改前验证明确单独标记 |
| 阅读助手正文 | 支持引用、任务列表、表格转义分隔符与行内代码、反引号/波浪线代码围栏；代码复制保留原始内容并反馈成功或失败 |
| 核对上下文 | 区分当前输入/附件和上次实际请求，展示字符数、附件数量/字节、请求模型/Provider、时间、上下文文件/字节及来源路径 |
| 理解 Code 预算 | 展示轮次、累计耗时、调用次数和连续失败；说明具体耗尽原因与下一步，耗尽状态不提供无法执行的继续动作 |
| 停止与恢复阅读 | 停止请求防重复点击并显示等待退出，失败后可重试；切回会话时先等待当前执行状态确认，轮询失败不视作已退出；聊天记录载入或轮询失败显示刷新入口 |
| 输入与键盘操作 | 按实际待发送消息合并计算输入/附件长度，超限时显示原因并禁用发送，错误与提示关联输入框；长代码可键盘聚焦，菜单焦点与窄屏布局已补齐 |

展示复用已有主题和执行视图，没有新增依赖。执行摘要与工具详情提供中英文文本，长路径与代码在局部滚动区域内阅读。

## 证据口径

- 执行摘要使用当前任务的服务端检查状态。其他轮次或运行的自动检查不能作为当前验证证据。
- 必跑检查返回需重跑状态时不计为通过；自动检查缺少或不匹配验证哈希、当前轮次已回滚时，不计为通过。回滚后的当前改动文件数显示为零。
- 修改前验证是基线，不代表修改后的必跑检查通过。
- 完成条件仍需显式复核；未确认显示 `0/N`，整体确认后显示 `N/N`，验证范围变化后显示需要重新确认。
- 字符数、文件字节数、调用次数分别展示；Provider 未提供 token 用量时明确该数据不可用，不推算 token 使用率。
- 原始 HTML 保持文本，危险链接不成为可执行链接；工具元数据按已支持的事件字段展示，不把整份原始日志当成摘要。
