## 本轮已实际修正的问题

1. **最后一次调用的回复无法完成后续操作。** 达到允许调用次数后不再立即锁住本地流程；第 N 次回复可以应用、测试、提交，尝试第 N+1 次才拒绝，次数不会增加。已有锁定预算不因重启解锁。
2. **审核或暂停后回滚使计时永久冻结。** 回滚退出等待与普通状态转换复用等待计时处理，恢复后继续累计活动时间。
3. **重启与确认恢复期间误耗预算。** 重载从最后持久化活动暂停时钟，排除停机及恢复等待；已真实耗尽的预算仍保留。
4. **HTTP 200 非 JSON、非对象或畸形内容绕过协议处理。** 统一为 MODEL_INVALID_OUTPUT，编码起草可使用已有有界反馈重试。明确 content_filter/refusal/tool_use 等未完成结果不能成为可应用补丁；原有长度截断错误保留。
5. **模型命令修改未读文件后仍继续起草。** 命令结束后比较完整验证输入与 Git 分支、HEAD、暂存条目；发现变化或无法检查则记录 COMMAND_WORKSPACE_CHANGED 并停止。覆盖成功、失败、超时及取消路径，保留实际磁盘/Git 状态供审阅。额度拒绝也释放预留命令槽位。
6. **用户选中的上下文文件被静默丢弃。** 保留归一化选择，在初始上下文未提供完整内容时明确提示缺失及整文件限制；审计同时记录选择、初始缺失和实际供给文件。该提示不等于强制模型只能修改选中文件。
7. **缺失或截断备份被当作空文件恢复。** 保留检查点历史；整个回滚链预检备份及应用哈希，新备份保存内容摘要；缺失/损坏时在任何写入前阻断。合法空文件仍正常恢复。修复备份后需重载服务重新读取检查点；旧格式继续兼容，但无法追溯确认已有备份损坏。
8. **失败应用及外部编辑影响回滚。** 成功恢复的失败应用标记为已恢复，避免污染后续回滚链；非 UTF-8 外部编辑按字节检测为冲突；原子替换失败清理本次临时文件。

新增 CHECKPOINT_UNAVAILABLE 与 COMMAND_WORKSPACE_CHANGED 已接入 API 409 和中英界面错误文案。

## 继续完善的优先级

这些功能可以继续开发，无需等待真实点击反馈；应按独立、可验证的小批次实施。

| 优先级 | 工作 | 验证目标 |
| --- | --- | --- |
| P1 | 每个任务独立工作区，明确命令写盘归属与恢复 | 两个任务共享源仓库但互不污染；命令修改能完整审阅、恢复；保护主工作区和原暂存 |
| P1 | 大文件区段读取与基于已读区段的精确修改 | 超整文件预算的真实文件可修复，未读部分保持字节不变；外部修改仍使预览失效 |
| P1 | 非 Git 任务与无需改动任务的本地完成流程 | 当前验证及逐项证据确认后可以明确完成；停止、回滚、过期结果不能借此完成 |
| P1 | 可重复的业务任务集与失败分类 | 单文件、多文件、上下文缺失、修复迭代、停止恢复使用同一组任务，报告实际结果而非主观成功率 |
| P2 | 按目标路径加载嵌套 AGENTS；补足 TS ESM/常用别名关联 | 只加载适用目录指令，完整供给/缺失可见；关联质量用固定任务比较 |
| P2 | 需求子目标拆解、逐项完成状态与跨轮证据 | 大需求每一项都有改动、验证和证据归属；保持原目标，不能仅凭模型自报完成 |

真实反馈主要用于评估模型在业务仓库中的成功率、需求理解质量和页面操作体验。本地模拟及全套测试不能替代这些结论。
